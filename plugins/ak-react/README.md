# ak-react

React and Next.js development with performance optimization guidelines and code quality scanning.

## Skills

| Skill | Description |
|-------|-------------|
| `react-best-practices` | 65 Vercel Engineering performance rules across 8 categories (critical to low impact) |
| `react-doctor` | Automated code quality scanner with 0-100 scoring and actionable diagnostics |

## Knowledge Base

- **full-guide.md** — Complete reference with all 65 rules and detailed code examples

## Usage

```bash
# Install the plugin
claude plugin add ak-react

# Use skills
/ak-react:react-best-practices
/ak-react:react-doctor
```
